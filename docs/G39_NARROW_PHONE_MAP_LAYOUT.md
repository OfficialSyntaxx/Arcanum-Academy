# G39 — Narrow-phone local map layout

At 360px and below, local-map destinations now use one column rather than compressing their label
and type into half-width controls. The map keeps its existing full-width SVG and 48px touch targets.

## iPhone acceptance

1. Open a busy local map at a 320px CSS viewport.
2. Confirm every destination occupies one full-width row with readable label and type.
3. Confirm the map remains visible, the panel scrolls, and no horizontal overflow appears.
