# G20 — Local map destination types

The existing numbered local-map list now states what each destination is: Gathering, Crafting,
Quest board, Combat, Tideglass clue, or Route. Marker colours match that role, so players can
recognise a clue or encounter before selecting it.

No map target, route, interaction rule, reward, progression value, asset, server behavior, or
hosting setting changed.

## iPhone acceptance

1. Open the Cinderhollow local map in portrait orientation.
2. Confirm Cinder Ore Vein reads **Gathering**, Cinderheart reads **Combat**, Cinder Crucible reads
   **Crafting**, Tideglass Brand reads **Tideglass clue**, and the exit reads **Route**.
3. Confirm each numbered button remains at least 48px tall and selecting it uses the normal route.
