# G19 — World collection journal

The existing Collection Log now identifies itself as an **Alderfell** journal rather than a
Shorelands-only ledger. Its diary section and locked-entry hint use the same world-wide language,
so Cinderhollow and Saltwake milestones read as part of a growing world.

No discovery definitions, diary requirements, rewards, progression data, server behavior, assets,
or hosting were changed.

## iPhone acceptance

1. Open **Log** from the tab bar.
2. Confirm the eyebrow reads **Alderfell discoveries** and the diary section reads **Alderfell
   diaries** in portrait orientation.
3. Confirm locked discoveries say **Keep exploring Alderfell** and the panel still closes normally.
