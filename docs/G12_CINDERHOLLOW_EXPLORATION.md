# G12 — Cinderhollow exploration depth

The Tideglass Trail now crosses Cinderhollow between the foothill mark and the Frostgate spire.
Players inspect a tideglass brand at the cavern's central fork before following the bearing north.

This is an authored exploration extension, not a new progression system: it reuses the existing
server-validated clue order, persistent clue ledger, mobile tracker, and unchanged 45-coin reward.
No new runtime asset, schema migration, hosting dependency, trading, or social write is added.
