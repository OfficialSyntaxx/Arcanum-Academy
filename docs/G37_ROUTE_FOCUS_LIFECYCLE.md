# G37 — Route-focus lifecycle

Map navigation begins movement immediately. The local target focus now survives that normal panel
dismissal and is cleared only when the player changes zones, where an old-zone marker would no
longer be relevant.

## iPhone acceptance

1. Select a distant destination from the local map and let travel begin.
2. Reopen the map while still in the same zone; confirm the target remains outlined.
3. Change zones and confirm no old-zone target remains focused.
