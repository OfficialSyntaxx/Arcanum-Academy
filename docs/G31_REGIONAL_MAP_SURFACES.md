# G31 — Regional map surfaces

Both map surfaces now use one light client-core colour catalog keyed by zone. The new tints mirror
each region's existing palette without loading textures or reading renderer state.

## iPhone acceptance

1. Open the minimap and local map in the Courtyard, Cinderhollow, and Ashen Overlook.
2. Confirm each region has a distinct readable map surface while routes, destinations, and the
   player arrow remain high contrast.
3. Confirm map opening, routing, and touch targets are unchanged.
