# G38 — Minimap route focus

The rotating minimap now outlines the locally selected map destination until the player changes
zones. It reuses the same local Hub focus as the full map and does not create a second route or
state authority.

## iPhone acceptance

1. Select a nearby destination from the local map.
2. Confirm its minimap marker receives a pale outline while it remains nearby.
3. Change zones and confirm the outline clears.
