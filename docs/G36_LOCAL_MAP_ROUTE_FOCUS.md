# G36 — Local map route focus

Selecting a destination from the local map now creates a short-lived local UI focus. Reopening the
map before movement begins outlines that chosen marker; the normal travel lifecycle clears it.

## iPhone acceptance

1. Choose a destination on the local map, then reopen the map before moving.
2. Confirm the selected destination has a pale outline and pressed state.
3. Begin travel and confirm the map closes and the focus clears with the existing travel lifecycle.
