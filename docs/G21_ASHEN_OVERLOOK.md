# G21 — Ashen Overlook

Ashen Overlook is an optional scenic branch reached by climbing from Cinderhollow's new Ashen Rise
landmark. It contains a quiet Ember Vista and a reciprocal return path, but no resources, combat,
items, rewards, or discovery requirements.

The existing server-authoritative travel handler permits only the Cinderhollow ↔ Ashen Overlook
pair. It reuses the existing atmosphere and procedural world renderer, so no runtime asset or
hosting cost is introduced.

## iPhone acceptance

1. Travel to Cinderhollow's Ashen Rise and choose **Climb**.
2. Confirm Ashen Overlook loads with the Ember Vista shown on the local map.
3. Use **Return to Cinderhollow** and confirm the reciprocal route works; no coins, items, or
   progress change should occur.
