# G27 — Elevation-aware local maps

The local map now uses a dashed path segment wherever two authored waypoints have different
terrain heights. This is data-driven, so it covers Ashen Overlook's Basalt Steps and future
elevated routes without special UI content.

## iPhone acceptance

1. Open the Ashen Overlook local map.
2. Confirm the short link between the two Basalt Steps labels is dashed.
3. Select the return route, travel to Cinderhollow, and confirm map dismissal and routing are
   unchanged.
