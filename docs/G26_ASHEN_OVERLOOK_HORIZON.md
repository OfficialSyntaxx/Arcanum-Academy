# G26 — Ashen Overlook horizon rim

Ember Vista is now backed by five low-cost procedural basalt crags outside the playable bounds.
They establish a volcanic horizon and preserve the overlook's open sky without adding any asset,
collision surface, route, or interactive system.

2. Confirm basalt crags frame the far horizon behind the vista pillars.
3. Confirm taps and movement still use only the authored overlook route; the outer rim is not an
