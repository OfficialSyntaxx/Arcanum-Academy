# G33 — Local map region context

The local map now places the current zone's authored name directly beneath its heading. It is small,
non-interactive context that remains readable after travel and works for every existing or future
zone without per-screen copy.

## iPhone acceptance

1. Open the local map in Cinderhollow and Ashen Overlook.
2. Confirm the region name is visible above the map without reducing destination touch targets.
3. Travel between the two zones and confirm the subtitle updates with the existing map lifecycle.
